工业物联网与时间序列基础模型

ChengShi Tech Ltd.，西安 · 联合创始人 & 首席 AI 科学家 · 2023–2025

联合创办公司，从 0 到 1 搭建其 AI 驱动的工业物联网平台，带领 25 人团队（含 3 名 AI 研究员）交付服务 200,000+ 居民用户与 2,000+ 企业客户、覆盖多个地区的生产系统。推进到商业合作阶段，并与 A 轮投资方（一家中国上市能源公司）对接，之后转为顾问角色。

  • 自适应多尺度分解的时间序列基础模型
    通过 Lipschitz 约束的跨时间尺度架构同时建模分钟级到月级的预测；混合专家框架中各专家按模态与区域用能模式分工，并从开放域时间序列数据集做迁移学习。
  • 异构图神经网络
    多层级结构（用户 → 区域/企业 → 城市），整合另类数据：天气、楼龄、上游工业信号（煤炭、金属冶炼）、管网使用历史。
  • 燃气泄漏预警系统（误报率 40%+ → 17%）
    以深度学习检测替代专家规则加统计的基线；以人机双轨核验的方式部署于生产。
  • 非对称损失下的需求预测
    在中国能源配额制度下，少购的代价是多购的 3–5 倍。初步结果显示区域燃气公司每年可节省 5–10% 成本；已排期生产部署，并附 3 年验证方案。
  • 面向日常运维的多模态 LLM 智能体
    接入 11 个独立本地数据库，以知识图谱增强的 RAG 为 120,000 本地用户分析、自动执行、可视化并解释状态与关键趋势。运行于合作方平台。
  • 数据基础设施
    来自 200,000+ 智能表计、分钟级粒度的 3 年历史数据；冷启动策略（区域级先验、预训练微调）以及带版本化 checkpoint 的模型生命周期管理。

早期 LLM 产品创业

联合创始人 / 首席工程师 · 兼职 · 2021–2023

与研究并行的两次创业，均属各自垂直领域最早的 LLM 系统生产部署之列。此处隐去公司名称。

  • 多智能体电商内容流水线
    带领 7 人团队搭建从市场情报抽取到自动上架的端到端流水线。混合 LLM 编排——GPT-4 负责规划与决策，Qwen-LoRA 负责低成本本地生成——在能力与推理成本之间取得平衡。微调 Stable Diffusion 做生成式产品设计（纹身图案、T 恤图形），并接入 Midjourney 与 Kling API 生成社媒视频。人在回路的设计允许半天一次的审核周期，其间系统自主运行。退出：技术栈（代码库与文档）被一家成熟的中型电商公司收购。
  • 面向咨询业务的 AI 辅助报告生成
    一个服务上市公司合规与竞争情报需求的 ESG 报告生成系统。通过微调语言模型实现 10× 的效率提升——初稿时间从 5 人团队的 2–3 周降至 2 天——并在生成质量与训练成本的权衡下主导了从微调 BERT 到 GPT-3.5 的技术演进。基于 2 年历史报告搭建标注流水线，把 ESG 标准映射到报告逻辑，把 PDF 文档转化为结构化训练数据。以内部工具形式交付，至今仍在使用。

学习式图像压缩

Deep Render Ltd. & 帝国理工学院（Innovate UK）· 研究科学家 / 研究助理 · 2020–2021

导师 William Knottenbelt 教授。开发了一套学习式（生成式）图像压缩系统，绕开 JPEG-2000 与 WebP 的专利壁垒，同时取得 30%+ 的压缩提升。独立贡献了面向高效算子的神经架构搜索框架，以及可微量化瓶颈设计（产品线 V0.1.3 内部使用）。
