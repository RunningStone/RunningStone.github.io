§1这轮实验做了什么

这套评估让三家厂商各三档，共 9 个模型完成相同的 27 类认知任务。我想检查哪些探针能在不同家族中区分模型的表现。如果每个家族至少有一个模型出现可测的准确率下降，就把该算子纳入跨家族可用集合。所有模型都满分或都无法完成的探针，需要调整难度。

上一轮有 4 个算子因所有家族均饱和而被剔除，另有题目可以直接查找上下文得到答案。这次重写了 6 个探针：serial_recall、multi_feature_binding、modus_tollens、instantiation、comparison 和 full_sort，使回答需要实际变换或计算。

重测后，跨家族可用算子为 23 个，上一轮为 17 个；被剔除的为 0 个，上一轮为 4 个。6 个重写探针均进入可用集合。其余 4 个——dereference、ref_resolve、set_operations、var_binding——保留用于家族内比较。

9 个模型、27 个算子，各测试 N 进行 30 次试验，共 50,220 次。由于生成器已重写，全部重新运行。费用合计约 $315，其中 Opus $249、Sonnet $49，合占 95%；其余 7 个模型合计不到 $17。

cliff_n 是平均准确率首次低于 0.80 的最小 N。同一行中数值越大，表示模型能处理的该类任务规模越大。各算子的 N 含义不同，不能直接跨行比较。分类列中 U 表示跨家族可用，K 表示仅保留用于家族内比较。

§4结果解读

这轮实验重点是调整题目。将复制和单行查表改为序列变换、两两比较后，跨家族可用算子从 17 个增加到 23 个，没有算子因全家族饱和被剔除。

例如，序列操作改为排序、逆序或选奇数位后，Google 两个较低档位的准确率为 10% 和 23%；特征关系计数中，Google pro 在最大 N 上只有 3%。这说明题目的计算要求会明显影响结果。其余 4 个算子保留用于家族内比较。

部分任务在最小 N 就已经过难，还需要降低起始难度，才能看清模型之间的差异。

准入条件：每个家族至少一个模型在测试网格内出现可测 cliff_n。该数值仅在同一算子内比较。本轮 |OP_UNIVERSAL| = 23、|OP_KEPT| = 27、|OP_REJECTED| = 0，上一轮为 17 / 23 / 4。

6 个重写探针均进入跨家族集合。serial_recall 中，flash-lite / flash 在最小 N 的准确率为 0.10 / 0.23，Claude 仍触顶；multi_feature_binding 使用 O(对象²) 的关系计数，gemini-2.5-pro 在最大 N 为 0.03，gpt-5.4-mini 触底。modus_tollens 使用 K=3 和 YES / NO / UNKNOWN / CONTRADICTION 四类答案，gpt-5.4-nano 在最小 N 为 0.43。instantiation 的 recursive_abductive 变体中，opus 为 1.00，较低档位出现悬崖。comparison 和 full_sort 改为派生键后，也能跨家族区分表现。

家族内保留项包括 var_binding（gpt-5.4 base 触顶，nano cliff_n=10）、dereference（gpt-5.4-nano / gemini-lite cliff_n=5，gpt-5.4 base ≥50）、set_operations（gemini-pro / Claude 触顶，较低档 Gemini 触底），以及 ref_resolve（仅 gpt-5.4-mini / gemini-flash 有悬崖）。

需要继续调整的是难度范围：abstraction 在九格均为 cliff_n=1，full_sort 在最小 N 为 0.47–0.70。它们满足准入条件，却无法充分显示模型梯度。

本轮 50,220 次试验全部重新执行，费用 $315.12。opus $249.33、sonnet $48.92，合占 95%；其余七个模型不到 $17。所有 cliff_n 使用 0.80 阈值。
