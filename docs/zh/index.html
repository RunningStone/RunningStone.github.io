研究智能体与后训练多模态与虚拟细胞系统与早期工作博客

人类是非遍历世界里不可复制的采样者，提供不可替代的多样性观测。模拟提供一个信息受限视角下的系综，并持续优化策略。智能机器贡献稳定的执行力。社会共同体塑造优化目标与奖励循环。

我长期的研究兴趣是长程、自我改进的智能体——能够接管目前由人承担的重复性工作。为了走到那一步，我在搭建完整的评估到训练闭环：受控环境、可复现的轨迹、把观察到的行为转化为训练信号的评估器，以及奖励驱动的后训练。在这些系统工作之外，我研究可靠长程智能的两个基础问题：任务结构如何限制多智能体的成功率，以及终身学习如何围绕生存压力下的遗忘–可塑性权衡被形式化。

更早的工作贯穿着同一种本能：理解架构的第一性原理，深入数据本身，把结果一路推到可度量地有效为止 ——突破学习式图像压缩的专利壁垒、用常规组织切片替代 £7,000+ 的空间转录组实验、部署服务 200,000+ 用户的工业物联网。相比孤立的新颖性，我更在意一个结果在停止成为 demo 之前能走多远。
