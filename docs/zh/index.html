研究智能体与后训练多模态与虚拟细胞系统与早期工作博客

人类是非遍历世界里不可复制的采样者，提供不可替代的多样性观测。模拟提供一个信息受限视角下的系综，并持续优化策略。智能机器贡献稳定的执行力。社会共同体塑造优化目标与奖励循环。

我研究能够长期工作、自我改进的智能体，希望它们能承担更多目前需要人反复处理的工作。我主要在搭建从评估到训练的完整流程：构造受控环境，记录可复现的运行轨迹，用评估器把行为转化为训练信号，再用这些信号做后训练。同时，我也在研究两个理论问题：任务结构怎样限制多智能体的成功率，以及如何描述生存压力下，终身学习中的遗忘与可塑性权衡。

此前，我做过学习式图像压缩、计算生物学和工业物联网：绕开图像压缩的专利限制，用常规组织切片推断原本需要 £7,000+ 空间转录组实验才能测得的信息，以及部署服务 200,000+ 用户的系统。这些工作让我习惯先弄清模型和数据，再处理实际使用中的限制。我在意研究结果能解决什么问题，以及它能否经得起持续使用。
