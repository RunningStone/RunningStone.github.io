Measuring Agent Safety with Control Barrier Functions用控制屏障函数描述 Agent 安全

2026-06-01agent-safetycontrol-barrier-functionformal-modelautonomous-driving

How can we describe safety along a trajectory?怎样描述一条轨迹的安全性

A yes-or-no judgement of an LLM agent trajectory leaves several questions open: which constraint was nearly violated, and how much room remained for another action? Control barrier functions offer a way to express that margin through a scalar function $h$ on the state. The safe set is $\{h\ge 0\}$, and a condition on each state transition can ensure that the trajectory stays in it. I use this formulation below to describe agent trajectories.

对 LLM agent 的轨迹只给出“安全”或“不安全”的判断，还回答不了一些问题：哪条约束最接近被违反，下一步还有多少余量？控制屏障函数用状态上的标量函数 $h$ 描述这种裕度，以 $\{h\ge 0\}$ 定义安全集，再通过约束每一步的状态转移，使轨迹保持在安全集内。下面尝试用这一表述描述 agent 轨迹。

For an agent, we do not have a known physical dynamics model or a directly observed physical state. The available inputs are the trace $\sigma$ and tool schema $S$. We therefore define $x_t=\alpha(\sigma_{\le t})$ from the observed prefix and place $h$ on that abstraction. A guarantee about the real trajectory then depends on how faithfully the abstraction represents it. The error band $\varepsilon$ records this dependence.

对 agent 而言，这里没有已知的物理动力学模型，也没有可以直接读取的物理状态。可用输入是轨迹 $\sigma$ 和工具 schema $S$，因此我们从已观测的前缀定义 $x_t=\alpha(\sigma_{\le t})$，再在这个抽象状态上定义 $h$。要把保证推广到真实轨迹，就需要说明抽象是否忠实；误差带 $\varepsilon$ 用来表达这一限制。

The comparisons with autonomous driving help identify the pieces needed here. Responsibility-Sensitive Safety (RSS) defines safe distances, parameters for other drivers and responsibility after the first dangerous moment. The Safety Force Field uses a potential over claimed sets; Hamilton-Jacobi reachability uses a game value to filter a policy; signal temporal logic assigns robustness values to temporal rules. The three agent routes below differ in how they obtain the state and $h$: from a schema, from a learned environment model, or through direct learning.

对照自动驾驶文献，可以看清这个框架需要哪些部分。Responsibility-Sensitive Safety（RSS）定义安全距离、对其他驾驶者的参数假设，以及首次危险时刻之后的责任；Safety Force Field 使用 claimed set 上的势函数；Hamilton-Jacobi 可达性通过博弈值函数过滤策略；信号时序逻辑为时序规则定义鲁棒度。下文三条 agent 路线的区别，主要是状态和 $h$ 的来源：工具 schema、学到的环境模型，或直接学习。

My take我的看法

I have previously tried to formalise agent safety as a Boolean property and then prove statements that added little to the definition. Keeping a numerical margin gives me more useful questions to work on: whether it stays non-negative, which constraint is closest to failure, and how large the uncertain region is.

我也曾把 agent 安全写成布尔性质，再去证明一些几乎只是重复定义的命题。保留数值裕度后，可以继续研究的问题更具体：它能否一直保持非负，哪条约束最接近失效，以及无法确定判断的区域有多大。

I also find the explicit assumptions in driving-safety work useful. Parameters describing other road users make the scope of a claim open to inspection and debate. For agents, specifying an attacker's channels and budget serves the same purpose: readers can see which adversaries the guarantee covers.

自动驾驶安全研究对假设的处理也值得借鉴。把其他道路使用者的行为写成参数后，结论适用于什么情形就可以被检查和讨论。对 agent 也一样：写明攻击者能控制的通道和预算，读者才能判断保证覆盖了哪些对手。

0One loop, three routes一条循环，三条路线

The three routes share a loop. The trace prefix is abstracted into $x_t=\alpha(\sigma_{\le t})$, and $h$ gives its safety margin. A one-step invariance check considers the worst observation allowed by the adversary model; the filter then accepts the proposed action or selects a fallback. Execution adds a new observation to the prefix. Components combine through $\min$, with $\arg\min$ identifying the limiting component. The error $\varepsilon$ sets the required filtering margin. The routes use different constructions of $h$.

三条路线使用同一循环：将轨迹前缀抽象为 $x_t=\alpha(\sigma_{\le t})$，由 $h$ 给出安全裕度；一步不变性检查考虑对手模型允许的最坏观测，过滤器据此放行候选动作或选择备用动作。执行后，新观测加入前缀。各分量通过 $\min$ 组合，由 $\arg\min$ 标出限制最紧的分量；误差 $\varepsilon$ 决定过滤所需的余量。三条路线分别用不同方式构造 $h$。

This route uses tool names, argument structures, effects and ordering rules declared in the schema. It requires no semantic interpretation for those properties; claims outside the schema remain outside its scope.

这条路线使用 schema 声明的工具名、参数结构、效果和调用顺序。对这些性质无需额外的语义解释；schema 没有描述的性质不在其适用范围内。

Interactions with the environment are used to infer, check and repair a transition model. The barrier is then compiled on that model, supporting lookahead, backward tracing of failures and searches for alternative paths.

先通过与环境交互建立、检查和修正转移模型，再在模型上构造屏障。显式模型支持前瞻模拟、回溯失效原因，以及搜索替代路径。

When neither a suitable schema nor an environment for probing is available, both the state representation and the barrier are learned. Their faithfulness must then be established separately before making a guarantee.

如果既没有可用的 schema，也无法探测环境，就需要学习状态表示和屏障函数。在提出保证之前，还必须单独验证这些表示的忠实程度。

A0

State: a labelled Kripke structure状态：带标签的 Kripke 结构

\[x_t=K(\sigma_{\le t})=(S,S_0,R,L),\qquad L(s_t)\supseteq\Sigma_t\]
\[\Sigma_{t+1}=\Sigma_t\cup\{\mathsf{post}(r):r=(\mathsf{tool},\mathsf{pattern},\mathsf{pre},\mathsf{post})\ \text{fires at }a_{t+1}\}\]

Each step adds a state. Tool names and effect rules with satisfied preconditions determine its atomic labels; their accumulated set $\Sigma_t$ represents the world state. The step operator appends the state and applies rules matching the call.

每一步增加一个状态。工具名与前置条件已满足的效果规则决定原子标签，累积集合 $\Sigma_t$ 表示世界状态。单步算子追加状态，并应用与本次调用匹配的规则。

Driving comparison:自动驾驶对照： RSS: a kinematic state obtained from declared vehicle parameters.RSS：由声明的车辆参数得到运动学状态。

B0

State: a position on a learned transition system状态：学到的转移系统上的位置

\[\mathcal G=(V,E,\mathsf{pre},\mathsf{eff},\mathsf{perm}),\qquad x_t=(v_t,w_t)\]
\[x_{t+1}=(v^\prime,\ \mathrm{apply}(\mathsf{eff}(e),w_t))\ \text{for the edge }e=(v_t,a_{t+1},v^\prime)\]

The inferred model has entity configurations as nodes and actions as edges, labelled with preconditions, effects and permissions. The state combines the current node with the world state. A step follows an edge and applies its effects.

归纳模型以实体配置为节点，以动作为边，并标注前置条件、效果和权限。状态由当前节点与世界状态组成；每一步沿边转移并应用对应效果。

Driving comparison:自动驾驶对照： Althoff: the models of ego and other vehicles from which occupancies are predicted.Althoff：用来预测占据集的自车与他车模型。

C0

State: a path in a learned space状态：学到的空间里的路径

\[\xi_s=(\mathsf{flow}_s,\mathsf{sens}_s,\mathsf{ctx}_s),\qquad v_s=\varphi(\xi_s)\in\mathbb R^d,\qquad x_t=p_t=\sum_{s\le t}v_s\]

The encoder maps label-free features, such as sender, recipient, sensitivity and context, to a direction at each step. The state accumulates these directions into a path. The same action can therefore reach a different state depending on its history.

编码器将发送者、接收者、敏感程度和上下文等不含标签的特征映射为每一步的方向，再累积成路径状态。因此，同一动作在不同历史之后会到达不同状态。

Driving comparison:自动驾驶对照： HJ with learned dynamics; neural value functions as the state representation.学到动力学的 HJ；神经值函数作为状态表示。

A1

Barrier: margins of declared constraints屏障：声明约束的裕度

\[h(x_t)=\min_{c\in\mathcal C_{\text{active}}}\ \mathrm{margin}_c(x_t),\qquad \mathrm{margin}_c\in\{\pm 1\}\ \text{or}\ x-k\]
\[\text{ordering: }\mathsf A[\neg\mathsf{tool}_v\ \mathcal U\ \mathsf{tool}_u],\qquad \text{effect: }\mathsf{AG}(\mathsf{tool}\Rightarrow\mathsf{AF}\,p)\]

Each declared constraint supplies a margin: a numerical gap for a numerical precondition, or a sign for a Boolean one. If all margins are signs, h reduces to the model-checking verdict for temporal formulas compiled from the dependency structure.

每条声明的约束提供一个裕度：数值前置条件用差值表示，布尔条件用符号表示。如果所有裕度都只有符号，h 就退化为依赖结构所编译时序公式的模型检查结果。

Driving comparison:自动驾驶对照： RSS: $d-d_{\min}$ with $d_{\min}$ in closed form from declared parameters.RSS：$d-d_{\min}$，$d_{\min}$ 由声明参数闭式给出。

B1

Barrier: a minimum of typed components屏障：带类型分量的最小值

\[h(x_t)=\min\{h_{\mathsf{act}},h_{\mathsf{perm}},h_{\mathsf{pre}},h_{\mathsf{post}},h_{\mathsf{temp}},h_{\mathsf{reach}}\}\]
\[h_{\mathsf{reach}}=-\,d,\qquad d=\min\#\{\text{constraints to relax before the goal is reachable}\}\]

Components measure action availability, permissions, precondition gaps, predicted-effect consistency, temporal obligations and reachability in constraint relaxations. Their values describe the margin to the safe-set boundary; their signs determine the safety verdict.

各分量分别描述动作是否存在、权限、前置条件差值、预测效果一致性、时序义务，以及用约束放松数衡量的可达性。数值表示相对安全边界的裕度，符号决定安全判断。

Driving comparison:自动驾驶对照： Althoff: occupancy separation; SFF: the potential $\rho_{AB}$ over intersecting claimed sets.Althoff：占据集间距；SFF：claimed set 相交上的势 $\rho_{AB}$。

C1

Barrier: a learned surface屏障：学到的曲面

\[h_\theta:\mathbb R^d\to\mathbb R,\qquad \mathcal C=\{p:\ h_\theta(p)\ge 0\},\qquad \text{safe}\iff\forall t:\ h_\theta(p_t)\ge 0\]

The learned function defines a safe region in path space and assigns a margin to each state. Training jointly learns the coordinates through the encoder and the boundary through the barrier surface.

学习到的函数在路径空间中定义安全区域，并为状态赋予裕度。训练同时学习编码器所确定的坐标和屏障曲面所确定的边界。

Driving comparison:自动驾驶对照： Neural CBFs and learned safety value functions.神经 CBF 与学到的安全值函数。

A2

Invariance: active constraints remain true不变性：当前约束继续成立

\[h\big(x_t\oplus\beta(a,o)\big)\ge(1-\lambda)\,h(x_t)\ \Longleftrightarrow\ \forall c\ \text{active}:\ c\ \text{holds after }(a,o)\]

With sign-valued margins, the check requires every active ordering, precondition and effect constraint to remain true after the proposed step. The schema is sufficient to decide this at each step.

裕度只有符号时，只需检查候选动作执行后，当前生效的顺序、前置条件和效果约束是否仍然成立。这一检查可以逐步依据 schema 完成。

Driving comparison:自动驾驶对照： RSS: proper response follows a fixed law; Lemma 5 establishes the induction for all traces.RSS：proper response 遵循固定规则，Lemma 5 为所有轨迹建立归纳证明。

B2

Invariance: one-step lookahead on the model不变性：在模型上前瞻一步

\[\min_i h_i\big(\mathrm{step}_{\mathcal G}(x_t,a)\big)\ \ge\ (1-\lambda)\,h(x_t)\]

Before execution, simulate the candidate action on the model: follow its edge, apply the effects and evaluate each component. The simulated successor must satisfy the discrete-time barrier condition.

执行前先在模型上模拟候选动作：沿对应边转移，应用效果，计算各分量，再检查模拟后继是否满足离散时间屏障条件。

Driving comparison:自动驾驶对照： Althoff: verify the next occupancy set online before committing to the manoeuvre.Althoff：在线验证下一步占据集后再执行操作。

C2

Invariance: different losses for safe and unsafe paths不变性：区分安全与不安全路径的损失

\[\mathcal L_{\text{safe}}=\sum_t\max\big(0,\ (1-\lambda)h_\theta(p_t)-h_\theta(p_{t+1})\big),\qquad \mathcal L_{\text{unsafe}}=\max\big(0,\ \min_t h_\theta(p_t)+m\big)\]

Apply the discrete barrier condition only to safe paths. For unsafe paths, a margin term pushes the minimum below zero. Requiring invariance on those paths would conflict with their required boundary crossing.

离散屏障条件只用于安全路径；对不安全路径，用裕度损失将最小值推至零以下。如果同时要求这些路径保持不变性，就会与它们必须穿越边界的要求冲突。

Driving comparison:自动驾驶对照： Learned certificates trained with the barrier condition as a constraint.以屏障条件为约束训练的学习型证书。

A3

Composition: a per-constraint vector组合：逐约束向量

\[h=\min_c h_c,\qquad i^\star=\arg\min_c h_c\ \text{names the violated constraint class}\]

The components come directly from the declared constraints. Their signs form a vector, and the first failed constraint supplies the attribution, without a separate hand-written classification.

分量直接来自声明的约束，其符号组成向量。第一条失效约束用于归因，无需另写一套分类。

Driving comparison:自动驾驶对照： RSS: pairwise proper responses combine through $\min$ under the star-shape construction, avoiding contradictory requirements.RSS：在 star-shape 构造下，通过 $\min$ 组合成对的 proper response，避免要求相互矛盾。

B3

Composition: classify by argmin, trace causes backwards组合：argmin 分型，沿轨迹回溯原因

\[i^\star=\arg\min_i h_i(x_{t_b}),\qquad t_{\text{root}}=\max\{s<t_b:\ \mathsf{pre}_{i^\star}\ \text{held at }s\}\]

The failed component identifies the violation type. A backward traversal finds the last step at which its precondition held, locating where the trajectory left that component's safe region.

失效分量给出违规类型。沿模型回溯其前置条件最后一次成立的位置，就可以定位轨迹何时离开该分量的安全区域。

Driving comparison:自动驾驶对照： RSS: responsibility is assigned by behaviour after $t_b$; the slice locates $t_b$ per component.RSS：责任由 $t_b$ 之后的行为判定；切片按分量定位 $t_b$。

C3

Composition: contract clauses as components组合：合约条款作为分量

\[h=\min(h_{\mathsf{NI}},h_{\mathsf{resp}}),\qquad \text{dual evasion requires both components to be driven below }0\]

Components represent assume-guarantee contract clauses, such as must-not-flow for non-interference and must-flow for responding to errors. Their dual structure is intended to make evasion harder: changing one component in the adversary's favour tends to worsen another.

分量对应 assume-guarantee 合约条款，例如要求非干涉的 must-not-flow，以及要求响应错误的 must-flow。对偶条款用于增加规避难度：对手朝有利方向改变一个分量时，往往会使另一个分量恶化。

Driving comparison:自动驾驶对照： SFF: the change of the potential decomposes into per-actor terms, each required to be non-positive.SFF：势的变化分解为逐 actor 的项，各自要求非正。

A4

Filter: deterministic, no model call过滤：确定性，零模型调用

\[a^\star=\begin{cases}a_{\text{task}}&\text{pattern check passes on }a_{\text{task}}\\ a_{\text{fallback}}&\text{otherwise}\end{cases}\]

The filter checks a candidate call against active constraints. It either allows the call or invokes the fallback, stopping and asking for guidance. With no sampling or semantic interpretation, the check is reproducible and can itself be verified.

过滤器根据当前约束检查候选调用，满足条件则放行，否则停止并询问。检查不涉及采样或语义解释，因此结果可复现，过滤器本身也可以接受验证。

Driving comparison:自动驾驶对照： RSS: proper response as a fixed fallback law; Certified Control: the checker is the trusted base.RSS：proper response 是固定的 fallback 律；Certified Control：检查器是可信基。

B4

Filter: simulate, then admit or reroute过滤：先模拟，再放行或改道

\[a^\star=\begin{cases}a_{\text{task}}&\mathrm{step}_{\mathcal G}(x_t,a_{\text{task}})\ \text{passes}\\ \text{a path in }\mathcal G\ \text{to the same goal, else }a_{\text{fallback}}&\text{otherwise}\end{cases}\]

If a candidate fails, search $\mathcal G$ for another path to the same goal with every component non-negative. Use the fallback when no such path exists.

候选动作未通过时，在 $\mathcal G$ 上寻找通向同一目标、各分量均保持非负的替代路径；找不到时执行备用动作。

Driving comparison:自动驾驶对照： Althoff: a verified fail-safe trajectory is kept available at every step.Althoff：每一步都保留一条验证过的 fail-safe 轨迹。

C4

Filter: one forward pass, a margin ε过滤：一次前向，余量 ε

\[a^\star=\begin{cases}a_{\text{task}}&\min_{o\in\mathcal D}h_\theta\big(p_t+\varphi(\xi(a_{\text{task}},o))\big)\ge(1-\lambda)h_\theta(p_t)+\epsilon\\ a_{\text{fallback}}&\text{otherwise}\end{cases}\]

Each candidate requires one encoder pass and one evaluation of $h_\theta$. The margin $\epsilon$ must account for learning error and the worst observation allowed by the adversary set.

每个候选动作需要一次编码器前向计算和一次 $h_\theta$ 求值。余量 $\epsilon$ 需覆盖学习误差及对手集合允许的最坏观测。

Driving comparison:自动驾驶对照： HJ least-restrictive filter: pass the task policy while $V\ge\epsilon$, otherwise the safe policy.HJ 最小干预过滤：$V\ge\epsilon$ 时放行任务策略，否则切换到安全策略。

A5

Fidelity: atom grounding error保真度：原子命题映射误差

\[\Pr\big[\,|h(\alpha(\sigma))-h^\star(\sigma)|>|h|\,\big]\le 1-p^{\,m},\qquad p=1\ \text{for schema-derived atoms}\]

Under the stated atom-correctness model, a verdict using $m$ atoms, each correct with probability $p$, has an abstraction-induced error bounded by $1-p^m$. Schema-derived atoms have $p=1$; interpreted atoms have $p<1$ and limit this route.

在所设定的原子正确性模型下，一次判断使用 $m$ 个原子、各自正确概率为 $p$ 时，抽象导致判断翻转的概率上界为 $1-p^m$。从 schema 读取的原子取 $p=1$；需要解释的原子取 $p<1$，构成这条路线的限制。

Driving comparison:自动驾驶对照： RSS Remark 2: induction fails if a parameter assumption is violated, for example when the front car brakes harder than assumed.RSS Remark 2：前车制动强于假设等参数偏差，会使归纳条件失效。

B5

Fidelity: coverage of the learned model保真度：学到的模型的覆盖率

\[\rho=\frac{|\mathcal G\cap\mathcal G^\star|}{|\mathcal G^\star|},\qquad \Pr[\text{missed violation on a length-}L\text{ trace}]\le(1-\rho)^L+\delta\]

Model error includes missing edges that can cause missed violations, and invented edges that can cause false alarms. An explicit miss-probability bound follows from an edge-wise coverage assumption, which must itself be justified.

模型误差包括两类：遗漏的边可能造成漏报，多出的边可能造成误报。在逐边覆盖率假设下可以得到漏报概率上界，但覆盖率假设本身仍需论证。

Driving comparison:自动驾驶对照： Althoff: sensor and model uncertainty enter as sets and enlarge the predicted occupancy.Althoff：传感与模型不确定性以集合进入，放大预测的占据集。

C5

Fidelity: contract-faithfulness of the encoder保真度：编码器的合约忠实性

\[\forall\sigma:\ \operatorname{sign}h^\star(\sigma)=\operatorname{sign}h^\sharp(p(\sigma))\ \text{for some }h^\sharp,\qquad h_\theta\le h^\sharp+\varepsilon\]

The guarantee requires an encoder that preserves the sign of the true margin for some surface $h^\sharp$, and a learned surface within $\varepsilon$ of it. Under those conditions, invariance with margin $\varepsilon$ implies safety of the concrete trajectory. These conditions need validation; the construction alone does not establish them.

保证要求编码器对某个曲面 $h^\sharp$ 保持真实裕度的符号，且学到的曲面与它相差不超过 $\varepsilon$。满足这些条件时，带余量 $\varepsilon$ 的不变性才能推出具体轨迹安全。条件需要验证，不能仅凭构造得到。

Driving comparison:自动驾驶对照： Verification of learned certificates; rollout-based certification of a learned filter.学习型证书的验证；对学到的过滤器做 rollout 认证。

A6

Adversary: atoms requiring interpretation对手：需要解释的原子命题

\[\text{attack surface}=\mathsf{Atoms}(h)\setminus\mathsf{Atoms}_S(h),\qquad \text{schema atoms cannot be forged}\]

In this adversary model, control over observations does not permit changing tool names or declared effects. Attacks can affect only atoms that the schema cannot decide, outside the directly formalisable portion.

在这里设定的对手模型中，控制观测不等于可以修改工具名或声明效果。攻击只能影响 schema 无法判定的原子，即直接形式化范围之外的部分。

Driving comparison:自动驾驶对照： IEEE 2846: the minimal set of assumptions about other road users, stated so it can be checked.IEEE 2846：对其他道路使用者的最小假设集，写成可检查的形式。

B6

Adversary: the environment leaving the model对手：真实环境偏离模型

\[\mathcal D=\{o:\ o\ \text{inconsistent with }\mathsf{eff}(e)\},\qquad \text{i.e. model error }\|\Delta\|\le\delta\]

Adversarial observations can correspond to environment transitions absent from the learned model. This treats the attack surface as model error, which the robust barrier condition must accommodate through its margin.

对手操控的观测可能对应偏离已学模型的环境转移。因此可以将这一攻击面表示为模型误差，并由鲁棒屏障条件预留相应余量。

Driving comparison:自动驾驶对照： RSS: an assumption violation (the other car braking harder than $a_{\max,\mathrm{brake}}$).RSS：假设被违反（对方刹车强于 $a_{\max,\mathrm{brake}}$）。

C6

Adversary: the encoder's input对手：编码器的输入

\[\mathsf{miss}_{\mathcal D}(h_\theta)=\sup_{\mathsf{atk}\in\mathcal D}\ \Pr_{\sigma\sim\mathsf{atk}}\big[h^\star(\sigma)<0\ \wedge\ \min_t h_\theta(p_t)\ge 0\big]\]

The adversary can shape the encoder's inputs and knows both the encoder and barrier surface. Evaluation therefore takes the worst case over the specified adversary family. Results must be reported with that family, since changing it changes the quantity measured.

对手可以操控编码器输入，并知晓编码器和屏障曲面。因此，评估取指定对手族中的最坏情况。报告结果时必须同时说明对手族，因为更换对手族也会改变所测量的量。

A7

Source of h: a closed form from the schemah 的来源：schema 给出的闭式表达

\[F_S(h)=1\ \Longrightarrow\ h\ \text{compiled from }S,\qquad h_{\mathrm{rev}}(x_t)=\#\{\text{steps before an irreversible declared effect}\}\]

If every atom is schema-decidable, h has a closed form derived from the declared structure. This includes $h_{\mathrm{rev}}$, the number of remaining steps during which a fallback can still prevent all declared irreversible effects.

所有原子均可由 schema 判定时，h 可以由声明结构给出闭式表达。其中 $h_{\mathrm{rev}}$ 表示还有多少步可以通过备用动作阻止全部已声明的不可逆效果。

Driving comparison:自动驾驶对照： RSS: known kinematics allow a closed-form $d_{\min}$.RSS：已知运动学支持 $d_{\min}$ 的闭式表达。

B7

Source of h: compiled on the learned modelh 的来源：在学到的模型上编译

\[\text{environment probe-able}\ \Longrightarrow\ h\ \text{compiled on }\mathcal G,\qquad h_{\mathrm{rev}}=\text{steps to an irreversible edge under the fallback}\]

Probing, resetting and observing the environment provide the basis for inferring the transition model. Components of h are then compiled on it, including a reversibility margin formulated as reachability on $\mathcal G$.

环境探测、重置和观测为归纳转移模型提供依据。随后在模型上编译 h 的各分量，包括表述为 $\mathcal G$ 上可达性问题的可逆性裕度。

Driving comparison:自动驾驶对照： Althoff and HJ: the certificate is computed on a known model of the dynamics.Althoff 与 HJ：证书在已知的动力学模型上计算。

C7

Source of h: learned, including the reversibility marginh 的来源：学习，包括可逆性裕度

\[F_S(h)<1\ \text{and no probe-able environment}\ \Longrightarrow\ h=h_\theta,\qquad h_{\mathrm{rev}}\ \text{must be learned too}\]

When neither a schema nor an environment model supplies the atoms, both the barrier and reversibility margin must be learned. This route covers more settings but provides fewer guarantees by construction; its faithfulness conditions need separate evidence.

schema 和环境模型都无法提供原子命题时，屏障及可逆性裕度都需要学习。这条路线覆盖的场景更广，但能够通过构造直接保证的性质更少，忠实性条件需要另行提供证据。

Driving comparison:自动驾驶对照： Neural CBFs; certificates learned from data and then verified.神经 CBF；从数据学出、再做验证的证书。

Five invariants of the framework框架的五条不变式

  1. The sign of $h$ determines the safety verdict, with zero marking the boundary. Retaining its value also records the margin.$h$ 的符号决定安全判断，零对应边界；保留数值还可以记录裕度。
  2. The guarantee requires the one-step invariance condition. Defining a violation as $h<0$ does not by itself prove that violations will be avoided.保证需要一步不变性条件。将违规定义为 $h<0$，本身并不能证明系统会避免违规。
  3. Composition uses $\min$ and requires an action that satisfies all active conditions simultaneously. At the first dangerous time, $\arg\min$ identifies the component used for attribution.用 $\min$ 组合时，必须存在能同时满足所有当前约束的动作。首次危险时刻的 $\arg\min$ 用于确定归因分量。
  4. The guarantee covers the worst case within the stated adversary parameters. Those parameters must be specified.保证覆盖已声明对手参数范围内的最坏情况，因此必须明确这些参数。
  5. Abstraction error creates an uncertainty band $\varepsilon$. To guarantee safety of the concrete trajectory, invariance must hold with this margin.抽象误差形成宽度为 $\varepsilon$ 的不确定带。要保证具体轨迹安全，不变性条件必须包含这一余量。

1Limits of the driving analogy与自动驾驶类比的适用范围

Three differences that require explicit treatment when applying the framework to agents.

将框架用于 agent 时，需要单独处理以下三点差异。

Without known dynamics, how should h be constructed?没有已知动力学时，怎样构造 h

\[F_S(h)=\frac{|\mathsf{Atoms}_S(h)|}{|\mathsf{Atoms}(h)|}\in[0,1]\]

RSS obtains a closed-form $d_{\min}$ from known kinematics. For an agent, the construction depends on what can be determined from the schema. If it covers every atom, compile directly; if an environment can be probed, compile on an inferred model; otherwise learn the function. Atoms requiring an interpretation of intent lie outside the schema and create the largest fidelity uncertainty.

RSS 依靠已知运动学得到 $d_{\min}$ 的闭式表达。对 agent，构造方式取决于 schema 能判定哪些原子命题：全部覆盖时直接编译；环境可探测时在归纳模型上编译；其余情形使用学习方法。需要解释意图的原子命题超出了 schema，也是忠实性误差最难控制的部分。

A response deadline makes the margin measurable有响应期限，才能计算剩余时间

\[\square\big(p\to\Diamond_{\le k}\,q\big):\qquad h=k-\#\{\text{steps since }p\}\ \text{while }q\ \text{has not occurred}\]

A finite prefix cannot give a distance to an unbounded claim that something will eventually happen. This framework therefore uses bounded temporal rules, whose margin is the time remaining. RSS similarly bounds response time by $\rho$. Here the deadline $k$ and predicate $q$ must be supplied.

仅凭有限轨迹前缀，无法为“某事最终会发生”这样的无界要求计算距离。因此，框架只使用有界时序规则，以剩余时间作为裕度。RSS 中的响应时间也受 $\rho$ 约束。这里的期限 $k$ 和谓词 $q$ 需要预先给定。

Non-interference is a property of two traces; authorisation is an assumption非干涉是两条轨迹的性质；授权是一条假设

\[h_{\mathsf{NI}}(x_t)=\mathsf{auth}(\sigma_{\le t})-\mathbf 1\big[\mathsf{sens}(a_t)\wedge\mathsf{ext}(a_t)\big]\]

Whether sending a document is a leak depends on the user's request as well as the agent trace. A single-trace monitor represents that context with an authorisation predicate. Setting $\mathsf{auth}\equiv\bot$ reduces it to a taint check and introduces structural false alarms. As with worst-case treatment of occluded regions in RSS, the assumption needs to be explicit: $\mathsf{auth}$ is a declared parameter, not inferred from the trace being judged.

发送文件是否构成泄露，还取决于用户的实际请求。单轨迹监测器通过授权谓词表达这一背景；设置 $\mathsf{auth}\equiv\bot$ 就退回污染检查，并产生结构性误报。类似 RSS 对遮挡区域采用最坏情况假设，这里的条件也应明确给出：$\mathsf{auth}$ 是声明的参数，不从正在接受判断的轨迹中推断。

The framework expresses safety as a margin on an abstract state and asks whether a one-step condition can keep it non-negative. Any resulting guarantee depends on the abstraction error and the adversary model. The three constructions make those dependencies easier to inspect: schema-based rules need declared structure, model-based certificates need environment coverage, and learned barriers need evidence of faithfulness.

这个框架用抽象状态上的裕度表达安全，并检查一步条件能否使其保持非负。由此得到的保证取决于抽象误差和对手模型。三种构造分别需要不同依据：基于 schema 的规则依赖声明结构，基于模型的证书依赖环境覆盖，学习得到的屏障则需要忠实性证据。
