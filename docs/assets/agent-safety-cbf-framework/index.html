Safety as Distance to a Boundary: A Control-Barrier Framework for Agent Trajectories安全是到边界的距离：Agent 轨迹的控制屏障框架

2026-09-08agent-safetycontrol-barrier-functionformal-modelautonomous-driving

What formal object should "agent safety" be?"agent 安全"应该是什么形式对象

Ask whether a trajectory of an LLM agent is safe and the usual answer is a verdict: yes or no, produced by a judge. A verdict has no distance in it. It cannot say how close the agent came, which constraint it was closest to breaking, or how many steps of margin were left. Control theory settled this question for robots and cars long ago: safety is a scalar function $h$ on the state, the safe set is $\{h\ge 0\}$, the value of $h$ is the signed distance to its boundary, and the guarantee comes from one inductive condition on how $h$ may change in a step. The framework below carries that object, unchanged, onto the trajectory of an agent.

问一条 LLM agent 轨迹安不安全，通常得到的是一个判决：是或否，由某个判官给出。判决里没有距离。它说不出 agent 离出事有多近、最接近违反的是哪条约束、还剩几步余量。控制理论早就为机器人和汽车回答了这个问题：安全是状态上的一个标量函数 $h$，安全集是 $\{h\ge 0\}$，$h$ 的值是到边界的带符号距离，保证来自一条关于 $h$ 每步允许怎样变化的归纳条件。下面的框架把这个对象原样搬到 agent 的轨迹上。

Two things are different from the physical case and the framework has to say so. There is no dynamics: the policy is a language model and the environment is open, so the only formal objects are the observed trace $\sigma$ and the tool schema $S$. And there is no physical state: the state is an abstraction $x_t=\alpha(\sigma_{\le t})$ of the prefix, and $h$ lives on that abstraction. Everything a guarantee can promise is therefore conditioned on how faithful the abstraction is; that error is written into the framework as a band $\varepsilon$ rather than hidden.

有两处和物理系统不同，框架必须明说。第一，没有动力学：策略是语言模型，环境是开放的，唯一的形式对象是观测到的轨迹 $\sigma$ 和工具 schema $S$。第二，没有物理状态：状态是前缀的抽象 $x_t=\alpha(\sigma_{\le t})$，$h$ 定义在这个抽象上。于是保证能承诺的一切都以抽象的忠实程度为条件；这个误差被写成框架里的一条带 $\varepsilon$，而不是藏起来。

Autonomous driving already has complete formal safety frameworks of exactly this shape, and they are placed beside every step: Responsibility-Sensitive Safety writes the boundary as a closed-form safe distance with the assumptions about other drivers as explicit parameters and defines responsibility by what a car does after the first dangerous moment; the Safety Force Field writes it as a potential over claimed sets; Hamilton-Jacobi reachability writes it as a game value and filters an untrusted policy through it; signal temporal logic gives a robustness value to any temporal rule. The three routes at the end differ only in where the state and $h$ come from: compiled from the schema, compiled on a learned environment model, or learned outright.

自动驾驶已经有了正是这个形状的完整形式化安全框架，它们被放在每一步旁边：Responsibility-Sensitive Safety 把边界写成闭式的安全距离、把对他车的假设写成显式参数、用第一个危险时刻之后的行为定义责任；Safety Force Field 把边界写成 claimed set 上的势函数；Hamilton-Jacobi 可达性把它写成博弈的值函数并用它过滤不可信的策略；信号时序逻辑给任何时序规则一个鲁棒度。最后的三条路线只在状态和 $h$ 从哪来上不同：从 schema 编译、在学到的环境模型上编译，或者直接学。

My take我的看法

The mistake I see most often, and made myself, is to formalise agent safety as a Boolean property and then prove things about the Boolean. Every theorem that comes out is a restatement of a definition, and every reviewer notices. The moment safety is a distance, the interesting statements exist: invariance, margin, blame, and the width of the band in which the verdict is honestly unknown.

我最常见到、自己也犯过的错，是把 agent 安全形式化成一个布尔性质，然后去证明关于这个布尔值的东西。证出来的每条定理都是定义的复述，每个审稿人都看得出来。安全一旦是距离，有意思的陈述才存在：不变性、余量、责任，以及判决诚实地"不知道"的那条带有多宽。

The second thing the driving literature teaches is that the assumptions about the other party are not a weakness to hide but a parameter to publish. RSS became a standard because its parameters can be argued about by a regulator. An agent framework whose attacker model is a list of channels and budgets, rather than an unstated "reasonable" adversary, can be argued about in the same way.

自动驾驶文献教的第二件事是：对另一方的假设不是要藏起来的弱点，而是要公开的参数。RSS 能成为标准，是因为它的参数可以由监管者来争论。一个把攻击者模型写成通道和预算清单、而不是一句"合理的对手"的 agent 框架，也可以被同样地争论。

0One loop, three routes一条循环，三条路线

Everything below is one loop instantiated three times. The state $x_t=\alpha(\sigma_{\le t})$ is an abstraction of the observed prefix; a barrier $h$ on it gives the margin; a one-step invariance condition, checked against the worst observation the adversary can produce, decides whether the task action passes the filter or the fallback runs; the next observation extends the prefix. Composition by $\min$ gives blame by $\arg\min$; the abstraction error $\varepsilon$ sets the filter's margin; where $h$ comes from is the one slot that differs between the routes. The diagram is drawn from the formulas.

下面的全部内容是同一条循环的三次实例化。状态 $x_t=\alpha(\sigma_{\le t})$ 是观测前缀的抽象；其上的屏障 $h$ 给出裕度；一步不变性条件按对手能给出的最坏观测检查，决定任务动作能否通过过滤、还是执行 fallback；下一次观测延长前缀。取 $\min$ 的组合给出 $\arg\min$ 归因；抽象误差 $\varepsilon$ 决定过滤的余量；$h$ 从哪来是三条路线唯一不同的槽位。这张图由公式画出。

box方块state状态barrier屏障invariance不变性compose & blame组合与归因filter过滤fidelity保真度adversary对手sources of hh 从哪来

Only what the schema declares is used: tool names, argument shapes, declared effects, declared ordering. Nothing is interpreted, so the abstraction is faithful by construction wherever it applies, and applies nowhere else.

只用 schema 声明出来的东西：工具名、参数形状、声明的效果、声明的顺序。什么都不解释，所以抽象在适用的地方按构造即忠实，在其他地方不适用。

First learn the environment as a transition system by interacting with it (probe, verify, repair), then compile the barrier on the learned model. The model is an explicit object, so a model-based safety analysis exists: lookahead, blame by backward slice, alternative paths.

先通过与环境交互（探针、验证、修复）把环境学成一个转移系统，再在学到的模型上编译屏障。模型是显式对象，所以有基于模型的安全分析：前瞻、后向切片归因、替代路径。

No schema to compile from and no environment to probe: the state is a path in a learned space and the barrier is a learned surface. The framework still applies; what changes is that faithfulness is a condition to be established, not a construction.

没有可编译的 schema，也没有可探针的环境：状态是学到的空间里的路径，屏障是学到的曲面。框架仍然适用；变化的是忠实性成了一个需要建立的条件，而不是构造出来的。

A0

State: a labelled Kripke structure状态：带标签的 Kripke 结构

\[x_t=K(\sigma_{\le t})=(S,S_0,R,L),\qquad L(s_t)\supseteq\Sigma_t\]
\[\Sigma_{t+1}=\Sigma_t\cup\{\mathsf{post}(r):r=(\mathsf{tool},\mathsf{pattern},\mathsf{pre},\mathsf{post})\ \text{fires at }a_{t+1}\}\]

One state per step. The labels are atomic propositions derived from the tool name and from effect rules whose preconditions already hold; the accumulated set $\Sigma_t$ is the world state. The step operator appends a state and fires the rules that match the call.

一步一个状态。标签是由工具名和前置条件已成立的 effect rule 派生的原子命题；累积集合 $\Sigma_t$ 就是世界状态。单步算子追加一个状态并触发与调用匹配的规则。

Driving side:自动驾驶侧： RSS: the kinematic state is read off declared vehicle parameters, not estimated.RSS：运动学状态直接从声明的车辆参数读出，不做估计。

B0

State: a position on a learned transition system状态：学到的转移系统上的位置

\[\mathcal G=(V,E,\mathsf{pre},\mathsf{eff},\mathsf{perm}),\qquad x_t=(v_t,w_t)\]
\[x_{t+1}=(v^\prime,\ \mathrm{apply}(\mathsf{eff}(e),w_t))\ \text{for the edge }e=(v_t,a_{t+1},v^\prime)\]

Nodes are entity configurations, edges are actions with preconditions, effects and required permissions; the model is induced from interaction rather than written. The state is the current node with the world state, and a step follows an edge and applies its effects.

节点是实体配置，边是带前置条件、效果、所需权限的动作；模型从交互归纳而来，不是手写的。状态是当前节点加世界状态，一步沿一条边走并应用其效果。

Driving side:自动驾驶侧： Althoff: the models of ego and other vehicles from which occupancies are predicted.Althoff：用来预测占据集的自车与他车模型。

C0

State: a path in a learned space状态：学到的空间里的路径

\[\xi_s=(\mathsf{flow}_s,\mathsf{sens}_s,\mathsf{ctx}_s),\qquad v_s=\varphi(\xi_s)\in\mathbb R^d,\qquad x_t=p_t=\sum_{s\le t}v_s\]

Each step is encoded from label-free features (who sends what to whom, how sensitive it is, in what context) into a direction, and the state is the cumulative path. The same step lands at different places depending on what came before, which is what makes safety a property of the path rather than of the step.

每一步从 label-free 特征（谁把什么发给谁、多敏感、在什么上下文）编码成一个方向，状态是累积路径。同一步因之前不同而落在不同位置，这正是安全成为路径属性而非单步属性的原因。

Driving side:自动驾驶侧： HJ with learned dynamics; neural value functions as the state representation.学到动力学的 HJ；神经值函数作为状态表示。

A1

Barrier: margins of declared constraints屏障：声明约束的裕度

\[h(x_t)=\min_{c\in\mathcal C_{\text{active}}}\ \mathrm{margin}_c(x_t),\qquad \mathrm{margin}_c\in\{\pm 1\}\ \text{or}\ x-k\]
\[\text{ordering: }\mathsf A[\neg\mathsf{tool}_v\ \mathcal U\ \mathsf{tool}_u],\qquad \text{effect: }\mathsf{AG}(\mathsf{tool}\Rightarrow\mathsf{AF}\,p)\]

Each declared constraint contributes a margin: a numeric precondition contributes its gap, a Boolean one contributes a sign. In the degenerate case every margin is a sign and $h$ is the model-checking verdict of the temporal formulas compiled from the dependency structure.

每条声明的约束贡献一个裕度：数值前置条件贡献间隙，布尔条件贡献符号。退化情形下所有裕度都是符号，$h$ 就是从依赖结构编译出的时序公式的 model-checking 判决。

Driving side:自动驾驶侧： RSS: $d-d_{\min}$ with $d_{\min}$ in closed form from declared parameters.RSS：$d-d_{\min}$，$d_{\min}$ 由声明参数闭式给出。

B1

Barrier: a minimum of typed components屏障：带类型分量的最小值

\[h(x_t)=\min\{h_{\mathsf{act}},h_{\mathsf{perm}},h_{\mathsf{pre}},h_{\mathsf{post}},h_{\mathsf{temp}},h_{\mathsf{reach}}\}\]
\[h_{\mathsf{reach}}=-\,d,\qquad d=\min\#\{\text{constraints to relax before the goal is reachable}\}\]

Each component is a margin on the learned model: existence of the edge, permission, precondition gap, consistency of the predicted effect, temporal obligations, and a reachability distance measured in constraint relaxations. The value is the distance to the boundary of the safe set, the sign is safety.

每个分量是学到的模型上的裕度：边是否存在、权限、前置条件间隙、预测效果的一致性、时序义务，以及以约束放松数计的可达性距离。数值是到安全集边界的距离，符号是安全。

Driving side:自动驾驶侧： Althoff: occupancy separation; SFF: the potential $\rho_{AB}$ over intersecting claimed sets.Althoff：占据集间距；SFF：claimed set 相交上的势 $\rho_{AB}$。

C1

Barrier: a learned surface屏障：学到的曲面

\[h_\theta:\mathbb R^d\to\mathbb R,\qquad \mathcal C=\{p:\ h_\theta(p)\ge 0\},\qquad \text{safe}\iff\forall t:\ h_\theta(p_t)\ge 0\]

The safe set is a learned region of the path space and the margin is the learned function's value. Two things are learned together: the coordinates (the encoder) and the boundary (the surface).

安全集是路径空间里学到的区域，裕度是学到的函数值。两样东西一起学：坐标系（编码器）和边界（曲面）。

Driving side:自动驾驶侧： Neural CBFs and learned safety value functions.神经 CBF 与学到的安全值函数。

A2

Invariance: no active constraint turns false不变性：没有活跃约束变假

\[h\big(x_t\oplus\beta(a,o)\big)\ge(1-\lambda)\,h(x_t)\ \Longleftrightarrow\ \forall c\ \text{active}:\ c\ \text{holds after }(a,o)\]

With sign-valued margins the condition collapses to a pattern check on the candidate step: every ordering, precondition and effect constraint that is currently active must still hold. It is decidable per step from the schema alone.

裕度取符号时，条件塌成对候选步的模式检查：当前活跃的每条顺序、前置、效果约束在这一步之后仍须成立。仅凭 schema 即可逐步判定。

Driving side:自动驾驶侧： RSS: proper response is a fixed law; Lemma 5 proves the induction once for all traces.RSS：proper response 是固定律；Lemma 5 对所有轨迹一次证完归纳。

B2

Invariance: one-step lookahead on the model不变性：在模型上前瞻一步

\[\min_i h_i\big(\mathrm{step}_{\mathcal G}(x_t,a)\big)\ \ge\ (1-\lambda)\,h(x_t)\]

Because the model is explicit, the candidate action can be simulated before it is executed: follow the edge, apply the effects, evaluate every component. The condition is the discrete-time barrier condition on the simulated successor.

模型是显式的，所以候选动作可以在执行前模拟：沿边走、应用效果、求每个分量。条件就是模拟后继上的离散时间屏障条件。

Driving side:自动驾驶侧： Althoff: verify the next occupancy set online before committing to the manoeuvre.Althoff：在线验证下一步占据集后再执行操作。

C2

Invariance: written into the loss, asymmetrically不变性：写进损失，且不对称

\[\mathcal L_{\text{safe}}=\sum_t\max\big(0,\ (1-\lambda)h_\theta(p_t)-h_\theta(p_{t+1})\big),\qquad \mathcal L_{\text{unsafe}}=\max\big(0,\ \min_t h_\theta(p_t)+m\big)\]

The discrete barrier condition is imposed on safe paths only; unsafe paths receive a margin term that pushes their minimum below zero. Imposing invariance on both would ask the surface to be invariant along paths that must cross it.

离散屏障条件只对安全路径施加；不安全路径得到一个把其最小值推到零以下的 margin 项。对两者都施加不变性，等于要求曲面沿必须穿过它的路径不变。

Driving side:自动驾驶侧： Learned certificates trained with the barrier condition as a constraint.以屏障条件为约束训练的学习型证书。

A3

Composition: a per-constraint vector组合：逐约束向量

\[h=\min_c h_c,\qquad i^\star=\arg\min_c h_c\ \text{names the violated constraint class}\]

The components are the declared constraints themselves, so the composition is a vector of signs and the blame is the constraint that first fails. No taxonomy is written by hand; the schema is the taxonomy.

分量就是声明的约束本身，组合是一个符号向量，责任是第一条失败的约束。没有手写的分类法；schema 就是分类法。

Driving side:自动驾驶侧： RSS: pairwise proper responses combined by $\min$ (star-shape), designed to never contradict.RSS：逐对 proper response 取 $\min$（star-shape），定义保证不矛盾。

B3

Composition: type by argmin, root by backward slice组合：argmin 分型，后向切片找根

\[i^\star=\arg\min_i h_i(x_{t_b}),\qquad t_{\text{root}}=\max\{s<t_b:\ \mathsf{pre}_{i^\star}\ \text{held at }s\}\]

The violated component names the type without a hand-written taxonomy; walking back along the model finds the step at which the precondition of that component was last satisfied, which is where the trajectory left the safe region for that component.

被违反的分量直接给出类型，不需要手写分类法；沿模型往回走，找到该分量的前置条件最后一次成立的步，那就是轨迹在这个分量上离开安全区的位置。

Driving side:自动驾驶侧： RSS: responsibility is assigned by behaviour after $t_b$; the slice locates $t_b$ per component.RSS：责任由 $t_b$ 之后的行为判定；切片按分量定位 $t_b$。

C3

Composition: contract clauses as components组合：合约条款作为分量

\[h=\min(h_{\mathsf{NI}},h_{\mathsf{resp}}),\qquad \text{dual evasion requires both components to be driven below }0\]

The components are the clauses of an assume-guarantee contract, for example must-not-flow (non-interference) and must-flow (respond to an error). Because the clauses are dual, an adversary who lowers one tends to raise the other, which is the sense in which the composition resists evasion.

分量是 assume-guarantee 合约的条款，例如 must-not-flow（非干涉）与 must-flow（对错误作出响应）。条款互为对偶，压低一个的对手往往会抬高另一个，这就是组合抵抗规避的含义。

Driving side:自动驾驶侧： SFF: the change of the potential decomposes into per-actor terms, each required to be non-positive.SFF：势的变化分解为逐 actor 的项，各自要求非正。

A4

Filter: deterministic, no model call过滤：确定性，零模型调用

\[a^\star=\begin{cases}a_{\text{task}}&\text{pattern check passes on }a_{\text{task}}\\ a_{\text{fallback}}&\text{otherwise}\end{cases}\]

The filter evaluates the candidate call against the active constraints and admits it or runs the fallback (stop and ask). Nothing is sampled and nothing is interpreted, so the filter is reproducible and can itself be verified.

过滤把候选调用对着活跃约束检查一遍，通过则放行，否则执行 fallback（停止并询问）。不采样、不解释，所以过滤可复现，且自身可被验证。

Driving side:自动驾驶侧： RSS: proper response as a fixed fallback law; Certified Control: the checker is the trusted base.RSS：proper response 是固定的 fallback 律；Certified Control：检查器是可信基。

B4

Filter: simulate, then admit or reroute过滤：先模拟，再放行或改道

\[a^\star=\begin{cases}a_{\text{task}}&\mathrm{step}_{\mathcal G}(x_t,a_{\text{task}})\ \text{passes}\\ \text{a path in }\mathcal G\ \text{to the same goal, else }a_{\text{fallback}}&\text{otherwise}\end{cases}\]

The model allows more than a stop: if the candidate fails, reachability on $\mathcal G$ can offer an alternative path to the same goal that keeps every component non-negative, and only when none exists does the fallback run.

有模型就不止能停：候选失败时，$\mathcal G$ 上的可达性可以给出一条到同一目标、且各分量保持非负的替代路径，只有不存在时才执行 fallback。

Driving side:自动驾驶侧： Althoff: a verified fail-safe trajectory is kept available at every step.Althoff：每一步都保留一条验证过的 fail-safe 轨迹。

C4

Filter: one forward pass, a margin ε过滤：一次前向，余量 ε

\[a^\star=\begin{cases}a_{\text{task}}&\min_{o\in\mathcal D}h_\theta\big(p_t+\varphi(\xi(a_{\text{task}},o))\big)\ge(1-\lambda)h_\theta(p_t)+\epsilon\\ a_{\text{fallback}}&\text{otherwise}\end{cases}\]

Filtering costs one encoder pass and one evaluation of $h_\theta$ per candidate; the margin $\epsilon$ is set by the learning error and by the worst observation in the adversary set.

过滤每个候选只花一次编码器前向和一次 $h_\theta$ 求值；余量 $\epsilon$ 由学习误差和对手集合里的最坏观测决定。

Driving side:自动驾驶侧： HJ least-restrictive filter: pass the task policy while $V\ge\epsilon$, otherwise the safe policy.HJ 最小干预过滤：$V\ge\epsilon$ 时放行任务策略，否则切换到安全策略。

A5

Fidelity: atom grounding error保真度：原子接地误差

\[\Pr\big[\,|h(\alpha(\sigma))-h^\star(\sigma)|>|h|\,\big]\le 1-p^{\,m},\qquad p=1\ \text{for schema-derived atoms}\]

If each atom is correct with probability $p$ and a verdict consults $m$ atoms, the chance that the abstraction flips the verdict is at most $1-p^m$. Atoms read from the schema have $p=1$; atoms that need interpretation have $p<1$, and that is the edge of this route.

若每个原子以概率 $p$ 正确、一次判决用到 $m$ 个原子，抽象翻转判决的概率至多 $1-p^m$。从 schema 读出的原子 $p=1$；需要解释的原子 $p<1$，那就是这条路线的边界。

Driving side:自动驾驶侧： RSS Remark 2: a mis-set parameter (the front car brakes harder than assumed) breaks the induction.RSS Remark 2：参数设错（前车刹得比假设强）归纳就断。

B5

Fidelity: coverage of the learned model保真度：学到的模型的覆盖率

\[\rho=\frac{|\mathcal G\cap\mathcal G^\star|}{|\mathcal G^\star|},\qquad \Pr[\text{missed violation on a length-}L\text{ trace}]\le(1-\rho)^L+\delta\]

The error is the gap between the induced model and the real environment, in both directions: edges the model lacks (missed violations) and edges it invents (false alarms). Under an edge-wise coverage assumption the miss probability has an explicit bound; the assumption itself has to be argued.

误差是归纳出的模型与真实环境之间的差，两个方向都有：模型缺的边（漏报）和模型多出的边（误报）。在逐边覆盖率假设下漏报概率有显式界；假设本身需要论证。

Driving side:自动驾驶侧： Althoff: sensor and model uncertainty enter as sets and enlarge the predicted occupancy.Althoff：传感与模型不确定性以集合进入，放大预测的占据集。

C5

Fidelity: contract-faithfulness of the encoder保真度：编码器的合约忠实性

\[\forall\sigma:\ \operatorname{sign}h^\star(\sigma)=\operatorname{sign}h^\sharp(p(\sigma))\ \text{for some }h^\sharp,\qquad h_\theta\le h^\sharp+\varepsilon\]

The guarantee is conditional: if the encoder preserves the sign of the true margin for some surface $h^\sharp$, and the learned surface is within $\varepsilon$ of it, then invariance of the learned surface with margin $\varepsilon$ implies safety of the concrete trajectory. The condition is testable but not constructed.

保证是条件式的：若编码器对某个曲面 $h^\sharp$ 保持真裕度的符号，且学到的曲面与它相差不超过 $\varepsilon$，则学到的曲面以余量 $\varepsilon$ 不变即蕴含具体轨迹安全。条件可检验，但不是构造出来的。

Driving side:自动驾驶侧： Verification of learned certificates; rollout-based certification of a learned filter.学习型证书的验证；对学到的过滤器做 rollout 认证。

A6

Adversary: only the uninterpretable atoms对手：只剩需要解释的原子

\[\text{attack surface}=\mathsf{Atoms}(h)\setminus\mathsf{Atoms}_S(h),\qquad \text{schema atoms cannot be forged}\]

An adversary who controls observations cannot change a tool name or a declared effect; it can only act on atoms the schema does not decide. The attack surface of this route is therefore exactly the complement of its formalisable part.

控制观测的对手改不了工具名或声明的效果；它只能作用在 schema 判定不了的原子上。这条路线的攻击面恰好是它可形式化部分的补集。

Driving side:自动驾驶侧： IEEE 2846: the minimal set of assumptions about other road users, stated so it can be checked.IEEE 2846：对其他道路使用者的最小假设集，写成可检查的形式。

B6

Adversary: the environment leaving the model对手：真实环境偏离模型

\[\mathcal D=\{o:\ o\ \text{inconsistent with }\mathsf{eff}(e)\},\qquad \text{i.e. model error }\|\Delta\|\le\delta\]

An observation the adversary can shape is an environment step that does not follow the learned edge; the attack surface is therefore the same object as the model error, and a robust barrier condition absorbs it as a margin.

对手能塑造的观测，就是不沿学到的边走的环境步；攻击面因此与模型误差是同一个对象，鲁棒屏障条件把它作为余量吸收。

Driving side:自动驾驶侧： RSS: an assumption violation (the other car braking harder than $a_{\max,\mathrm{brake}}$).RSS：假设被违反（对方刹车强于 $a_{\max,\mathrm{brake}}$）。

C6

Adversary: the encoder's input对手：编码器的输入

\[\mathsf{miss}_{\mathcal D}(h_\theta)=\sup_{\mathsf{atk}\in\mathcal D}\ \Pr_{\sigma\sim\mathsf{atk}}\big[h^\star(\sigma)<0\ \wedge\ \min_t h_\theta(p_t)\ge 0\big]\]

Everything the encoder reads can be shaped by the adversary, so the metric is the worst case over the adversary family, with the adversary given the encoder and the surface. Changing the family changes the number; that is a property of the framework, not a defect of the estimate.

编码器读到的一切都可被对手塑造，所以指标是对手族上的最坏情况，且对手拿到编码器和曲面。换对手族数字就变；这是框架的性质，不是估计的缺陷。

Driving side:自动驾驶侧： HJI: the disturbance is a player with the informational advantage; $\exists\pi^u\ \forall\pi^d$.HJI：扰动是拥有信息优势的博弈方；$\exists\pi^u\ \forall\pi^d$。

A7

Source of h: closed form from the schemah 的来源：从 schema 闭式

\[F_S(h)=1\ \Longrightarrow\ h\ \text{compiled from }S,\qquad h_{\mathrm{rev}}(x_t)=\#\{\text{steps before an irreversible declared effect}\}\]

When every atom is schema-decidable, $h$ is a closed-form function of the declared structure, including the reversibility margin $h_{\mathrm{rev}}$: how many steps remain in which the fallback can still prevent every irreversible declared effect.

当每个原子都可由 schema 判定时，$h$ 是声明结构的闭式函数，包括可逆性裕度 $h_{\mathrm{rev}}$：还剩几步 fallback 仍能阻止全部不可逆的声明效果。

Driving side:自动驾驶侧： RSS: $d_{\min}$ is closed form because the kinematics are known.RSS：$d_{\min}$ 能闭式是因为运动学已知。

B7

Source of h: compiled on the learned modelh 的来源：在学到的模型上编译

\[\text{environment probe-able}\ \Longrightarrow\ h\ \text{compiled on }\mathcal G,\qquad h_{\mathrm{rev}}=\text{steps to an irreversible edge under the fallback}\]

Wherever the environment can be probed, reset and observed, the model can be induced and every component of $h$ compiled on it, including the reversibility margin as a reachability question on $\mathcal G$.

只要环境可探针、可 reset、可观测，模型就能归纳出来，$h$ 的每个分量都能在它上面编译，包括作为 $\mathcal G$ 上可达性问题的可逆性裕度。

Driving side:自动驾驶侧： Althoff and HJ: the certificate is computed on a known model of the dynamics.Althoff 与 HJ：证书在已知的动力学模型上计算。

C7

Source of h: learned, including the reversibility marginh 的来源：学习，包括可逆性裕度

\[F_S(h)<1\ \text{and no probe-able environment}\ \Longrightarrow\ h=h_\theta,\qquad h_{\mathrm{rev}}\ \text{must be learned too}\]

When neither the schema nor an environment model can supply the atoms, the surface is learned, and so is the reversibility margin. This is the route with the widest reach and the weakest construction, and the framework says exactly which conditions it must establish to earn a guarantee.

当 schema 和环境模型都给不出原子时，曲面是学的，可逆性裕度也是学的。这是覆盖最广、构造最弱的一条路线，框架恰好说清了它要建立哪些条件才配得上保证。

Driving side:自动驾驶侧： Neural CBFs; certificates learned from data and then verified.神经 CBF；从数据学出、再做验证的证书。

This route has nothing specific in this box.这条路线在这个方块里没有特别之处。

Five invariants of the framework框架的五条不变式

  1. Safety is the zero level set of $h$; every Boolean statement about safety is a statement about $\operatorname{sign}(h)$ and nothing is lost by keeping the value.安全是 $h$ 的零水平集；任何关于安全的布尔陈述都是关于 $\operatorname{sign}(h)$ 的陈述，保留数值不丢任何东西。
  2. The only source of a guarantee is the one-step invariance condition; "if a rule is violated then $h<0$" is a definition, not a theorem.保证的唯一来源是一步不变性条件；"若违规则 $h<0$"是定义，不是定理。
  3. Components compose by $\min$ and only if one action can satisfy all active conditions at once; $\arg\min$ at the first dangerous time is the blame.分量以 $\min$ 组合，且只在一个动作能同时满足所有活跃条件时成立；第一个危险时刻的 $\arg\min$ 就是责任。
  4. The assumptions about the adversary are parameters of the framework, never an empty slot; the guarantee is stated for the worst case inside them.对手的假设是框架的参数，永远不是空槽；保证是对参数内部的最坏情况陈述的。
  5. The abstraction error is a band $\varepsilon$ that widens the region in which the verdict is unknown; a guarantee on the concrete trajectory needs the invariance to hold with margin $\varepsilon$.抽象误差是一条带 $\varepsilon$，它加宽判决未知的区域；对具体轨迹的保证需要不变性以余量 $\varepsilon$ 成立。

1Where the analogy to driving stops与自动驾驶的类比在哪里断开

Three places where an agent is not a car, and what the framework does about each.

agent 不是汽车的三处，以及框架对每一处的处理。

There is no dynamics, so where h comes from is a decision没有动力学，所以 h 从哪来是一个决定

\[F_S(h)=\frac{|\mathsf{Atoms}_S(h)|}{|\mathsf{Atoms}(h)|}\in[0,1]\]

RSS can write $d_{\min}$ in closed form because the kinematics are known. An agent's transition law is a language model. The fraction of the atoms of $h$ that the schema decides is what selects the route: all of them, compile from the schema; a probe-able environment, compile on a learned model; otherwise learn. Atoms that need the intent behind the trace sit outside the schema, and they are where every route's fidelity band is widest.

RSS 能把 $d_{\min}$ 写成闭式是因为运动学已知。agent 的转移律是一个语言模型。$h$ 的原子里有多少能由 schema 判定，决定走哪条路线：全部能，就从 schema 编译；环境可探针，就在学到的模型上编译；否则就学。需要轨迹背后意图的原子落在 schema 之外，也是每条路线保真度带最宽的地方。

Liveness has no margin; only bounded response does活性没有裕度，只有有界响应有

\[\square\big(p\to\Diamond_{\le k}\,q\big):\qquad h=k-\#\{\text{steps since }p\}\ \text{while }q\ \text{has not occurred}\]

"Something good eventually happens" cannot be given a distance on a finite prefix, and the driving frameworks never try: RSS bounds the response time $\rho$. The framework admits a temporal rule only in its bounded form, whose margin is the time left. The bound $k$ and the predicate $q$ are supplied, not inferred.

"好事终将发生"在有限前缀上给不出距离，自动驾驶框架也从不尝试：RSS 给响应时间 $\rho$ 加了界。框架只承认有界形式的时序规则，其裕度是剩余时间。界 $k$ 和谓词 $q$ 是供给的，不是推断的。

Non-interference is a property of two traces; authorisation is an assumption非干涉是两条轨迹的性质；授权是一条假设

\[h_{\mathsf{NI}}(x_t)=\mathsf{auth}(\sigma_{\le t})-\mathbf 1\big[\mathsf{sens}(a_t)\wedge\mathsf{ext}(a_t)\big]\]

Whether sending a document is a leak depends on a second trace: what the user actually asked for. A single-trace monitor can only fold that into an authorisation predicate, and $\mathsf{auth}\equiv\bot$ recovers the taint check with its structural false alarms. RSS treats an occluded region the same way, by assuming the worst behind it. So $\mathsf{auth}$ is declared as a parameter of the assumptions, never learned from the trace it is judging.

发一份文件算不算泄露，取决于第二条轨迹：用户实际要求了什么。单轨迹 monitor 只能把它折进一个授权谓词，$\mathsf{auth}\equiv\bot$ 就退回带结构性误报的 taint 检查。RSS 对遮挡区域也是这样处理的：假设后面是最坏情况。所以 $\mathsf{auth}$ 被声明为假设的参数，永远不从它正在判定的轨迹里学出来。

So what is agent safety, formally? A scalar margin on an abstract state, kept non-negative by a one-step condition, with the abstraction error and the adversary both written as parameters of the statement. The three routes are three answers to where the margin comes from, and the driving literature already shows what each answer costs: a closed form needs a known law, a compiled certificate needs a model, and a learned surface needs a faithfulness condition it must earn.

那么 agent 安全在形式上是什么？抽象状态上的一个标量裕度，由一步条件保持非负，抽象误差和对手都写成陈述的参数。三条路线是"裕度从哪来"的三个答案，而自动驾驶文献已经展示了每个答案的代价：闭式需要已知的定律，编译出的证书需要模型，学到的曲面需要它必须自己挣来的忠实性条件。
